# design/ — 浏览器草稿（视觉真源的起点）

## 文件

| 文件 | 用途 |
| --- | --- |
| `tokens.css` | **唯一参数真源**。`--pc-*` 只在这里定义，HTML 与 Java 都读它（Java 读它生成的 JSON） |
| `theme.css` | 卡面组件样式（`.card/.bar/.box/.icon/.info`）。**只使用参数，不定义参数** |
| `card.html` | 静态草稿：五档强调色、2× 放大、内容边界；带阴影/高光开关 |
| `animation.html` | 动画草稿：竖条原地展开 + 内容滑出；锚点可拖、可切右对齐 |
| `measure.html` | **测量页**：纯黑底、只有卡、无任何装饰。给像素对照当输入 |
| `measure.py` | 看图算数（纯函数）。量的对象就是 `measure.html` / harness 里的那三段式卡 |
| `test_measure.py` | 拿**已知答案的合成图**钉住 `measure.py`；外加"像素扫描 vs DOM 矩形"的端到端自检 |
| `compare.py` | 对照表 CLI：设计图 vs 游戏截图，按卡高归一，输出差异并给客观门 |
| `shot.py` | 无头浏览器截图（固定视口 + 设备像素比），可选导出 DOM 矩形 |
| `icons/` | 从 1.20.1 客户端 jar 抽的真实物品贴图 —— 用真素材才判断得准 |
| `*-draft.png` | Edge 无头截图，给不方便开浏览器时看 |

## 规矩（Q4：限定子集，清单外报错）

- `tokens.css` 的 `:root` / `:root[data-theme=...]` 里**只放标量 token**，那是唯一会被
  `tools/css_tokens.py` 抽取的部分。清单外的自定义属性 → 抽取脚本**直接失败退出**。
  （静默失败最毒：上一版用 AUI 时 `radial-gradient` 不解析也不报错。）
- **几何与文字宽度一律不进转换**，就地写死。卡宽在游戏里跟名字走，浏览器里算不准 ——
  上一版想把这块也烘成确定值，就是"HTML 当贴图"死掉的根。
- **卡面参数不许在 `theme.css` 里再定义一遍**。v1 就是两边各存一份、重名 18 个键，
  于是改了 `tokens.css` 以后草稿页面纹丝不动 —— 而抽取器只管 `tokens.css`，不会拦。

## 怎么量"还原了没有"

```
python design/shot.py design/measure.html --geometry   # 出 design/measure.png + DOM 矩形
python design/compare.py design/measure.png <游戏测量页> --expect 4
```

游戏侧的测量页由 harness 自动产出：`./gradlew runClient -PharnessAuto=shot` 会多拍一张
`pickupcard-measure`（纯黑底、无辅助线、无读数）。

**为什么底色是纯黑**：投影是半透明的黑，叠在纯黑上等于没叠，自己就消失了。
于是"卡片之外就是纯底"成立，不用为测量往渲染里加任何"关投影"的开关 ——
而"投影关没关"已经有一个键了（`--pc-shadow-alpha`），再开一个口子就是第二真源。

`compare.py` 的客观门只管**结构项**：竖条宽/高、两处间隙、图标格宽、级差、固定的是哪条边。
卡宽一类跟着字体走的数是内容项，只报不判 —— 浏览器和游戏的字体不是一个。

## 动画：竖条是隧道口，卡片是火车

`animation.html` 里这条动画**不是**宽度从 0 长到自然宽 —— 那会把内容挤变形。
它是：**竖条原地出现（坐标全程不变）**，内容保持自身尺寸，从竖条后面平移到最终位置，
被竖条右侧的裁剪窗一点点"放出来"。新卡从上方插入，把旧卡往下挤。

两种出隧道方式可切：

| 方式 | 做法 | 谁先出现 |
| --- | --- | --- |
| 火车（默认） | 裁剪窗定宽，内容 `translateX(-100% → 0)` | 数字端先出 |
| 拉幕 | 内容不动，裁剪窗宽度 `0 → 自然宽` | 名字端先出 |

两条实测（DOM 几何，非目测）：竖条 x 恒定 668.0、内容自身宽恒定 187.8、
可见宽 99 → 188。**没有拉伸，只有位移。**

（`animation.html` 里"竖条固定在屏宽 75%"那段几何冲突已经被 M2 定案解决：
默认改成**右缘对齐**，内容再长也不出屏。）
