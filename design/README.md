# design/ — 浏览器草稿（视觉真源的起点）

## 文件

| 文件 | 用途 |
| --- | --- |
| `theme.css` | **token 正本**：`:root` 里只放标量（长度/颜色/时长），两套预设（深色玻璃 / 浅色） |
| `card.html` | 静态草稿：五档强调色、2× 放大、内容边界；带阴影/高光开关（将来配置界面要暴露的键） |
| `animation.html` | 动画草稿：从稀有度竖条向右展开 + 新卡把旧卡挤下去；锚点可拖、可切右对齐 |
| `icons/` | 从 1.20.1 客户端 jar 抽的真实物品贴图 —— 用真素材才判断得准 |
| `*-draft.png` | Edge 无头截图（playwright），给不方便开浏览器时看 |

## 规矩（Q4：限定子集，清单外报错）

- `theme.css` 的 `:root` / `[data-theme]` 里**只放标量 token**，那是唯一会被
  `tools/css_tokens.py` 抽取的部分。
- **几何与文字宽度一律不进转换**，就地写死。卡宽在游戏里跟名字走，浏览器里算不准 ——
  上一版想把这块也烘成确定值，就是"HTML 当贴图"死掉的根。
- 清单外的 CSS 属性 → 抽取脚本**直接失败退出**，不静默忽略。
  （静默失败最毒：上一版用 AUI 时 `radial-gradient` 不解析也不报错。）
