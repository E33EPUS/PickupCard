# design/ — 浏览器草稿（视觉真源的起点）

## 这里放什么

`card.html` 是三段式卡面的**浏览器草稿**。视觉参数先在这里调，调顺了再由
`tools/css_tokens.py` 抽成 `assets/pickupcard/styles/default.json`。

**为什么不在游戏里调**：浏览器改一行看一眼是秒级，进游戏是分钟级。上一版美术定不了稿，
一半的账要记在"反馈周期太长"上。

## 规矩（Q4：限定子集，清单外报错）

- `:root` 里**只放标量 token**：长度 / 颜色 / 角度 / 时长。这一段是唯一会被抽取的部分。
- **几何与文字相关的一律不进转换**，就地写死并标注"示意"。卡宽在游戏里跟名字走，
  在浏览器里算不准——上一版想把这部分也烘成确定值，就是"HTML 当贴图"死掉的根。
- 用了清单外的 CSS 属性，`tools/css_tokens.py` **直接失败退出**，不静默忽略。
  （静默失败最毒：上一版用 AUI 时 `radial-gradient` 不解析也不报错。）

## 产物

- `card.html` —— 草稿本体
- `card-draft.png` —— 用 Edge 无头截图（`playwright`，脚本见提交说明），给不方便开浏览器时看
- `icons/` —— 从 1.20.1 客户端 jar 抽出来的真实物品贴图，草稿里用真素材才判断得准
